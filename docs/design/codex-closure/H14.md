# H14: one account for the spend of a turn

## Acceptance criterion

A cost that is not available stays unknown. A retry adds to the spend instead
of replacing it. Cancelling releases a reservation once. No subsystem of a turn
spends invisibly.

## Already there

- The in-memory turn ledger (`src/autonomy_budget.py`) charges the main stream,
  the compactor and the recovery ladder, with admission checks at round start.
- `src/budget_account.py` books delegated workers per run: reserve, reconcile,
  release, with unpriced usage reading as unknown cost.
- Non-streaming calls carry an observed usage receipt into the trace.

## Added

- `src/turn_spend.py` (new): a per-turn account installed for the life of one
  agent turn (`install` / `uninstall`, a context variable). Every non-streaming
  model call inside it is booked per attempt under a purpose.
  - `CallSpend.observe`: one attempt that reported usage; attempts add.
  - `CallSpend.note_unknown_attempt`: an attempt whose outcome is uncertain
    (timeout after the request was written).
  - `CallSpend.settle(outcome)`: idempotent; books tokens and cost, records
    unknown usage (answer without usage, uncertain outcome, cancel while in
    flight), or releases the reservation when nothing was spent.
  - Cost rule: local endpoint is a known zero; remote without a price is an
    unpriced cost; any unknown call makes the total read `unknown`.
  - `TurnAccount.begin`: in `enforce` mode, asks the loop's admission check and
    reserves an estimate; refuses with `TurnSpendExceeded` before the call.
  - `TurnAccount.record_main`: mirrors main rounds for the breakdown.
  - `TurnAccount.close`: settles anything still open, once.
  - `spend_purpose` (context manager), `_spend_purpose` argument, or the
    calling module name as a fallback label.
  - `explain(run_id)`: per purpose tokens, calls, attempts, cost.
- `src/budget_account.py`: schema version 2 (additive columns `purpose`,
  `usage_unknown`, `attempts`; a version 1 file is read as is and upgraded on
  the first write). `reserve`/`reconcile` take the new keyword arguments;
  `release` now says whether it freed anything; `snapshot` gains
  `unknown_usage_calls` and a `purposes` breakdown.
- `src/llm_core.py::llm_call_async`: books each call; wraps the caller's
  `on_outcome_unknown`; treats cancellation as its own outcome. Compaction and
  recovery calls (identified by their trace phase) are recorded but not charged
  twice.
- `src/agent_loop.py` (small): installs the account next to the trace run id,
  binds the ledger charge and the existing admission check, mirrors main rounds,
  reports `metrics.turn_spend`, labels the verifier and the two synthesis calls.
- Purposes set explicitly for the advisor, deep research, the workflow model
  node and memory consolidation.
- Setting `agent_turn_spend`: `off` / `record` (default) / `enforce`.
- Read surfaces: `GET /api/runs/{run_id}/spend`; `GET /api/runs/{run_id}/budget`
  now includes the breakdown; MCP tool `run_spend` (workers server).

## Limits

- Only `llm_call_async` and its fallback wrappers are booked. The synchronous
  `llm_call` (about eighteen call sites) has its own HTTP path, no usage
  receipt and no access to the turn's context, so those calls are not in the
  account.
- A call made on another thread or event loop without copying the context (the
  workflow model node runs its coroutine through a helper) is not attributed to
  the turn.
- Streaming calls outside the main loop (the main rounds are mirrored, other
  streams are not booked).
- The ledger charge for non-loop calls only counts usage the engine reported.
  A call that reported nothing is unknown in the account and adds nothing to the
  ledger; the ledger has no notion of unknown.
- `enforce` refuses the call; the caller sees `TurnSpendExceeded` and each
  auxiliary caller handles it as it handles any failed call.
