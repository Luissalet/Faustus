## Archivos y autoridad

Puntos de extensión iniciales: `src/mcp_manager.py`, `src/extension_manifest.py`, `src/skill_import_review.py`, `src/skill_governance.py`. Identificar callers, tests y write set real antes de editar. No crear una autoridad paralela.

## Implementación

1. Manifests/versiones/envs aislados y secretos por propietario

2. Descubierto, instalado, conectado, publicado y probado separados

3. Update staged y rollback con datos retenidos

4. Schemas exactos, límites, conflictos y revocación inmediata

## Criterios de cierre

- Ready requiere prueba pertinente

- Plugin no hereda sandbox ficticio

- Un fallo de transporte no reintenta mutación

## Entrega del agente

Incluir diff, tests realmente ejecutados, resultados, limitaciones, migración/flag/rollback y puntos pendientes. No afirmar éxito de motores por un mock; no ejecutar modelos ni instalar dependencias sin plan autorizado. Un paquete grande se divide en PR homogéneos.
